In Slay the Princess, you can go down many different routes in any order, and the information you learn about the story pieces together in different combinations.
For the basic prototype, it had to be a mechanical advantage, obviously. So, I made it such that each path has a key, which is necessary to complete that path, but also makes the other path easier.
I didn't get to do several of those coding tricks because they were related to the player (like inputs and movement), and I just downloaded a preset for a first person player.
I'm not sure if you wanted me to make the whole player and movement from scratch, but this was already a several hour long project. It's reasonable for an Asynch class, but I'm just saying figuring out and adding player movement might have been a lot more time.
A lot of this project was getting back used to making something real and applicable in Unity for me.
