In Slay the Princess, you can go down many different routes in any order, and the information you learn about the story pieces together in different combinations.
For the basic prototype, it had to be a mechanical advantage, obviously. So, I made it such that each path has a key, which is necessary to complete that path, but also makes the other path easier.
Additionally, I added power-ups to each route, which you have to go out of your way to obtain, but they make the routes easier, encouraging the player to explore (if the physical scope of the world were larger)
There are assets used from free libraries for some visual rocks, background music, sound effects, and the default 1st player movement.
The objective it to free up the routes to two seperate goals by picking up "keys", which remove "doors" blocking your way.
